# Authority boundary

The Domain Harness package is declarative metadata. Its dependency list names
the exact Genes it owns. Optional route hints participate only in Shadow Council
selection; an equal best claim from multiple Harnesses fails closed and requires
explicit selection.

Admission checks the package identity, strict SemVer, exact artifact hash,
runtime requirement, required dependencies, and trust evidence. Admission and
enablement do not execute the artifact, add an effect capability, approve an
operation, issue a permit, or change the constitutional Source binding.

Parliament remains the policy authority for planned operations.
ReferenceMonitor remains the sole issuer of scoped, one-shot effect permits.
Neither component is replaceable or configurable through a Domain Harness
manifest. Every Gene effect continues through the normal policy, approval,
permit, executor, and receipt path.
